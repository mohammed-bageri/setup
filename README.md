# setup

One-line setup for my Mac and Linux (CachyOS) machines:

```
curl -fsSL https://raw.githubusercontent.com/mohammed-bageri/setup/main/install | bash
```

It installs git and the GitHub CLI, signs in to GitHub in the browser, clones my (private)
workstation repo and runs its `./install`. This repo holds only that script; it's published
from the workstation repo.
